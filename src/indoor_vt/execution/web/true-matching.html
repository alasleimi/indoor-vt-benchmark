How the violation bars compare MPUrge with the actual true matches

For a returned edge that violates the bound, look up the observed peak from the same source as . If also violates it, this is an expected violation. If the true pair satisfies it, it is an unnecessary violation. If the true counterpart was discarded, the classification is unavailable.

A wrong output edge has different sources at its two ends. We therefore classify both endpoints with equal weight, instead of choosing an arbitrary direction. A segment's height is its endpoint count divided by twice the number of final matches. The total bar height remains exactly the fraction of final matches violating the bound. An edge whose endpoints disagree contributes half to each applicable segment; hover shows that disagreement count.
