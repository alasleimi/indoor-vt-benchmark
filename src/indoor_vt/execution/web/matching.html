Score reliability and metric definitions

Precision: fraction of accepted pairs from the same source. Recall: fraction of available same-source correspondences accepted. F1: their harmonic mean.

Counts are pooled over every unique fingerprint pair used by local MPUrge across the room. A missed correspondence includes a true pair lost during size unification. This is peak identity matching, not the map’s 0.5 m F1 tolerance. Metrics and pair ordering follow the selected matching stage; the reliability chart always uses first-round dissimilarities.

Ground truth uses retained native path identities, carried through the exact noise realization and sorting. These labels and native gains never enter the matcher.

What the matrix shows

Each column is a peak in the horizontal fingerprint; each row is a peak in the vertical fingerprint. Header bars show native path gain on a relative dB scale. Matching uses ranges only.

MPUrge optionally equalizes profile lengths, according to this configuration, then calculates δ = α × range difference + (1 − α) × pattern discrepancy. It identifies reciprocal best choices and applies the order cross-check. A circle marks an accepted match in the selected overlay. Final matches include all rounds: later rounds recompute scores on the remaining peaks, but those later scores are not shown in this matrix. A square means the peaks share a true source, including the direct-path AP.

Both shapes indicate a correct accepted match. A circle alone is incorrect. A square alone is a correspondence not accepted in the selected overlay. Unscored grey cells retain truth markers so exclusions stay visible. Matrices use the lower survey index as the horizontal fingerprint, matching the room evaluation.
