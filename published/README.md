# Published calibration snapshot

This directory contains the data for the public results explorer and a separate
replayable delay-only calibration dataset. Binary payloads use **Git LFS**;
ordinary Git commits contain small pointer files.

```sh
git lfs install
git lfs pull
```

`v6/meta.json` indexes 110 completed **initial calibration presets**: 72 VT,
8 raw localization, and 30 SMART-LEA pipelines. It records exact parameters,
artifact hashes, code identities, reuse provenance, and result-column descriptors.
`v6/manifest.json` provides checksums and sizes of the published files.

`v6/columns/*.bin.gz` contains losslessly compressed, content-addressed columns.
Identical columns are shared. Metric values remain IEEE-754 float64, without
rounding or case subsampling. The browser downloads only the selected methods'
columns, verifies hashes, and calculates statistics in a worker. Median, P90,
RMSE, F1 and CDFs remain conditional on the chosen filters. The four uint8
condition columns are row-major: room index, AP subset index (`A`, `B`, `A+B`),
index into the track's sorted noise levels, and layout index plus one (zero
for VT survey-map cases). Metric column length is the number of cases.

`v6/calibration-inputs.zip` includes all 2,288 active calibration delay files:
8 rooms × 2 APs × 11 acquisitions (survey and 10 query layouts) × 13 noise/track
conditions. The NPZ files are copied byte-for-byte after checking their source
manifest hashes. The ZIP also contains the calibration room design, survey and
query coordinates, evaluator-only source truth, seed registry, per-measurement
seeds, and observation/native-channel identities. No test-room observations are
included. The original design hash identifies the complete local design; the
exported `design.json` is explicitly its calibration subset.

Use [read_published_data.py](../scripts/read_published_data.py) to load the ZIP
without extraction. Estimator observations and query/source ground truth are
returned separately. For example, after `uv sync --frozen`:

```sh
uv run python scripts/read_published_data.py
```

The full native NIST outputs (power, phase, angles, path geometry), receiver
waveforms, simulator workspaces, historical revisions and diagnostic caches
remain in the original local `data/` and `runs/` directories. They are not
deleted, moved or replaced by this export. This snapshot is sufficient to replay
the delay-only inputs; it is not a backup of every original simulator artifact.

The local source-data inventory and Git bundle taken before publication live in
`runs/development/publication-checkpoint/`. A verified export is generated by:

```sh
.venv/Scripts/python.exe scripts/export_results_site.py --include-inputs
```

This command writes only `published/v6/` and the derived explorer index. Keep
the original acquisitions and audit history. Never force-add `data/` or `runs/`
to Git. LFS storage for this snapshot is approximately 73 MiB, not gigabytes.
